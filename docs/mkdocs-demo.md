# Демопроект «Помощник по MkDocs»

1. В конструкторе откройте **Проекты → Создать проект** и выберите шаблон **Помощник по MkDocs**.
2. Оставьте предзаполненное имя или задайте своё. Выберите модели генерации и эмбеддингов и укажите параметры провайдеров, если они не настроены в окружении. Нажмите **Создать проект**.
3. Во вкладке **Документы** появятся 20 источников. Индекс строится при первом запросе к корпусу. Для проверки откройте **Чат** и спросите «Что происходит при предупреждении во время сборки со включённым `strict`?». Ожидается ответ об остановке обработки со ссылкой на документ `11-preview-and-urls.txt`.
4. Во вкладке **Наборы вопросов** откройте «Документация MkDocs 1.6.1». В нём 90 вопросов, включая 16 без ответа в корпусе. Для запуска через интерфейс подтвердите проверку выбранных вопросов. Используйте `tuning` для подбора настроек и `test` для итогового сравнения.

Шаблон создаёт отдельную копию проекта с собственными версиями документов и набора. При создании проекта запросы к моделям не выполняются. Все вопросы получают статус **Не проверен** и проходят обычный процесс ручного подтверждения в приложении.

## Состав и происхождение

Набор хранится в [`backend/datasets/mkdocs_demo/`](../backend/datasets/mkdocs_demo/). В `corpus/` находятся 20 самостоятельных разделов англоязычного руководства MkDocs 1.6.1. Каждый файл содержит ссылку на строки исходника в закреплённом коммите. Ссылки также собраны в `sources.json`. У текста нормализованы переводы строк и пробелы в конце строк. Лицензия источника сохранена в `LICENSE-MkDocs.txt`.

В `questions.json` хранятся русскоязычные вопросы на факты, условия и исключения, перечисления и поиск по нескольким разделам. Для вопросов с ответом указаны эталон, категория, подтверждающие выдержки в точности по корпусу и имена соответствующих документов. Для вопросов без ответа указано объяснение, которое в приложении видно в эталоне отказа. Выдержки связываются с версиями документов при создании проекта.

Для автоматизации можно отправить настройки проекта в `POST /api/v1/public/provider/projects/demo/mkdocs`. Тело запроса совпадает с обычным созданием проекта.
