# Схемы для ДЗ 2 и ДЗ 3

Для каждой схемы есть изображение PNG и редактируемый файл BPMN 2.0 XML
с координатами элементов (BPMN DI). Процессы описательные, `isExecutable=false`:
это схемы для обсуждения и сдачи задания, а не программы для workflow-движка.

## ДЗ 2 — эксплуатация

`hw2-operation` описывает текущий RAG-проект на 24.10.2026 на уровне основного
успешного сценария и ошибок поиска/генерации. Два самостоятельных процесса:
подготовка базы знаний и обработка вопроса по уже подготовленной базе.
Подготовка обобщает одиночную загрузку; ZIP-операции не детализированы.
Валидация, чтение истории и запись в SQL показаны укрупнённо; отдельные ветки
для каждого возможного инфраструктурного отказа не приведены.

При сбое поиска возвращается ошибка, LLM не вызывается. Если поиск успешен,
но фрагментов нет, генерация продолжается с пустым контекстом и статусом
`no_context`. Это фактическое поведение, а не рекомендация по качеству ответов.
Основание: `backend/api/upload.py`, `backend/api/chat.py`.

## ДЗ 3 — автоматическая смена LLM

`hw3-model-switch` — предлагаемый процесс, которого пока нет в коде.
Триггер: еженедельная оценка текущей модели. Неудовлетворительная оценка
запускает подбор замены. Ошибка оценки текущей модели трактуется как
неудовлетворительный результат. Кандидаты проверяются без переключения
рабочего проекта; после переключения выполняются контрольные запросы.

Меняется только LLM. Документы, эмбеддер, индекс и параметры поиска
фиксируются для сопоставимости результатов. При смене эмбеддера требуется
другая схема с построением нового индекса.

Числа на схеме — предлагаемые требования, а не результаты эксперимента:

- Качество: не менее 85% правильных и подтверждённых документами ответов
  на фиксированном наборе размеченных вопросов; не ниже результата текущей LLM.
- p95 времени ответа на том же наборе: не более 10 секунд.
- Стоимость: не выше заданного проектом бюджета; проверять бюджет до прогонов.
- Максимум три кандидата и 30 минут на один цикл. Прогоны ограничиваются
  оставшимся временем и бюджетом. Ошибка или тайм-аут проверки отклоняет кандидата.

Остановка: смена не нужна, кандидатов/ресурса нет, лимиты исчерпаны,
смена прошла успешно либо контроль после смены не пройден и выполнен откат.
Уведомление ответственного изображает проектируемую задачу сервиса;
никаких сообщений при подготовке этих файлов не отправлялось.

## Файлы

- `hw2-operation.png` / `hw2-operation.bpmn`
- `hw3-model-switch.png` / `hw3-model-switch.bpmn`

PNG и BPMN строятся из одного описания расположения элементов.
Проверены достижимость узлов, отсутствие незавершённых веток и ссылки XML.
Изображения просмотрены визуально. Импорт в конкретный BPMN-редактор
не проверялся; оформление после импорта может отличаться от PNG.
