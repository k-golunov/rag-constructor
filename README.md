# RAG Constructor

Конструктор ассистентов для вопросов по документам: Angular-интерфейс, FastAPI API, PostgreSQL для настроек и истории, Qdrant для поиска. Текущая версия — прототип MVP. Состояние на 24.10.2026 и приоритетные проблемы описаны в [анализе проекта](docs/project-status.md).

## Реализованные возможности

- Создание, редактирование, просмотр и удаление проектов.
- Настройка моделей, ключей, URL провайдеров, системного промпта и размера чанков.
- Загрузка PDF с текстовым слоем, TXT, DOCX и ZIP через интерфейс или API.
- Рекурсивное разбиение текста, OpenAI-совместимые эмбеддинги, индексация в Qdrant.
- Чат с поиском документов и сохранением истории в PostgreSQL.
- Model Card каждого проекта: предпросмотр, ручное описание, история версий и экспорт Markdown/Word.

OCR, HTML/CSV, локальный HuggingFace-эмбеддер и потоковые ответы не реализованы. Некоторые настройки формы сохраняются, но ещё не влияют на пайплайн. Ошибка поиска может привести к ответу без документов; удаление источника пока не удаляет его векторы.

## Локальный запуск

Нужны Docker Compose, Python 3.12 и Node.js с npm. Backend ставится через Poetry: версии зависимостей зафиксированы в `poetry.lock`, виртуальное окружение создаётся в `./.venv` (см. `poetry.toml`). Полная инструкция по окружению — [docs/development.md](docs/development.md).

Из корня репозитория:

```bash
cp .env.example .env
# Замените OPENAI_API_KEY=sk-... в .env действительным ключом.
docker compose up -d postgres qdrant redis
./scripts/bootstrap.sh      # poetry install + pre-commit install
poetry run uvicorn backend.main:app --reload
```

То же через `make`: `make setup`, `make run`, `make test`, `make lint`.

В другом терминале из корня:

```bash
cd frontend
npm install --legacy-peer-deps
npm start
```

Адреса: [интерфейс](http://localhost:4200), [Swagger](http://127.0.0.1:8000/docs), [OpenAPI](http://127.0.0.1:8000/openapi.json). При старте API создаёт БД при необходимости и применяет миграции. `/health` не проверяет доступность зависимостей.

Создайте проект, задайте модели и ключи, загрузите файл на странице проекта и проверьте статус источника `completed`. Затем задайте вопрос во вкладке чата. Размерность эмбеддингов должна совпадать с выбранной моделью. Изменение модели не перестраивает существующий индекс.

Compose также предусматривает `docker compose up --build` для всего стека, но контейнерный сценарий в рамках анализа не проверялся. Перед его использованием учтите [ограничения конфигурации](docs/operations.md).
